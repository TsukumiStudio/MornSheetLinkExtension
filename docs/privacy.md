# プライバシーポリシー

Morn Sheet Link Extension は、Google スプレッドシートの選択範囲へのリンクを、名前付きのリンクとしてクリップボードにコピーする拡張機能です。

## 使用する情報

ユーザーがEx項目を実行したときに、開いているスプレッドシートのファイル名、タブ名、選択範囲、ページURLを読み取り、ブラウザ内でリンクを生成します。生成したHTMLリンクと表示名を端末のクリップボードに書き込みます。

## 情報の送信・保存

本拡張機能は、取得した情報を開発者や第三者のサーバーへ送信しません。アクセス解析、広告、トラッキング、外部コードの読み込みを行いません。取得した情報を拡張機能のストレージへ保存することもありません。

クリップボードの内容はユーザーの端末とOSによって管理されます。貼り付け操作を行った先のアプリやサービスでの取り扱いは、そのアプリやサービスの方針に従います。

## 権限

- `clipboardWrite`：ユーザーが実行したとき、生成したリンクをクリップボードへ書き込むために使用します。クリップボードの読み取り権限は要求しません。
- Google スプレッドシートのページへのアクセス：メニュー項目の追加と、リンク生成に必要なページ情報の読み取りに使用します。
