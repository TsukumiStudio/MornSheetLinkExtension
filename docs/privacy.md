# プライバシーポリシー

Morn Sheet Link Extension は、Google スプレッドシートの選択範囲をハイパーリンクとしてコピーする拡張機能です。

運営：TSUKUMI STUDIO／更新：2026年9月11日

## 使用する情報

「この範囲へのリンクを取得Ex」の実行時に、ファイル名・タブ名・選択範囲・ページURLを読み取ります。端末内でリンクを作り、HTMLリンクとリンク名をクリップボードへ書き込みます。

行全体の選択時はA列、列全体の選択時は1行目のセルの値を読み取り、リンク名に使います。複数選択では先頭と末尾の要素名を取得します。表示中のシートの数式バーから取得します。シートの内容や共有権限も変更しません。

## 送信・保存

拡張機能は、要素名の取得のために通信しません。取得した情報を外部に送信したり、拡張内に保存したりすることはありません。広告・アクセス解析・追跡・外部コードの読み込みもありません。

クリップボードは端末のOSが管理します。貼り付け後の情報は、貼り付け先の方針に従って扱われます。

## 権限

- `clipboardWrite`：リンクの書き込みに使用。クリップボードは読み取りません。
- シートへのアクセス：メニューの追加と、リンク作成に必要な情報の取得に使用。
