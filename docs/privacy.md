# プライバシーポリシー

Morn Sheet Link Extension は、Google スプレッドシートの選択範囲をハイパーリンクとしてコピーする拡張機能です。

運営：TSUKUMI STUDIO／更新：2026年9月8日

## 使用する情報

「この範囲へのリンクを作成 Ex」の実行時に、ファイル名・タブ名・選択範囲・ページURLを読み取ります。端末内でリンクを作り、HTMLリンクとリンク名をクリップボードへ書き込みます。

セルの内容や認証情報は読み取りません。シートの内容や共有権限も変更しません。

## 送信・保存

取得した情報の外部送信・拡張内への保存は行いません。広告・アクセス解析・追跡・外部コードの読み込みもありません。

クリップボードは端末のOSが管理します。貼り付け後の情報は、貼り付け先の方針に従って扱われます。

## 権限

- `clipboardWrite`：リンクの書き込みに使用。クリップボードは読み取りません。
- シートへのアクセス：メニューの追加と、リンク作成に必要な情報の取得に使用。
