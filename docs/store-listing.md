# Chrome ウェブストア掲載内容

## 名前

Morn Sheet Link Extension

## 概要

Google スプレッドシートの選択範囲を、ファイル名_タブ名_範囲の名前付きリンクとしてコピー。

## 詳細説明

スプレッドシートの範囲を共有するとき、長いURLの代わりに内容が分かる名前付きリンクをコピーできます。

例：売上管理_9月_B2:D10

使い方
1. Google スプレッドシートでセルや行・列の範囲を選択します。
2. 右クリックし、「セルでの他の操作項目を表示」を開きます。行や列を選択している場合は対応するメニューを開きます。
3. 「この範囲へのリンクを作成 Ex」を選びます。
4. リンクの貼り付けに対応したアプリへ貼り付けます。

HTMLの貼り付けに対応したアプリでは、選択範囲へのクリック可能なリンクとして貼り付けられます。プレーンテキストのみのアプリでは表示名だけになります。貼り付け先によってリンクの扱いは異なります。

通常のセル、連続範囲、行全体、列全体に対応。日本語・英語のスプレッドシートメニューに対応します。名前付き範囲や離れた複数範囲には対応していません。

データの外部送信、広告、アクセス解析はありません。
Google の公式製品ではありません。Google スプレッドシートの画面変更によって機能の調整が必要になることがあります。

## プライバシー申告用

- 単一用途：Google スプレッドシートの選択範囲へのリンクを、ファイル名・タブ名・範囲を含む表示名でコピーする。
- clipboardWrite の理由：ユーザーによるEx項目の実行時に、HTMLリンクとプレーンテキストをクリップボードへ書き込むため。
- サイトアクセスの理由：スプレッドシートのメニューへの項目追加と、開いているファイル名・タブ名・選択範囲・URLの取得に必要。
- リモートコード：使用しない。実行するコードはすべて拡張のZIPに含む。
- データ処理：ページ情報をブラウザ内で処理し、クリップボードに書き込む。開発者への収集・送信・永続保存は行わない。

## 公開手順

1. `node --test content.test.cjs` を実行する。
2. `python3 scripts/package.py` でアップロード用ZIPを作る。
3. 開発者ダッシュボードへZIPをアップロードする。
4. この説明文、アイコン、スクリーンショット、小さいプロモーション画像を登録する。
5. 公開したプライバシーポリシーのURLと、実際のサポート連絡先を設定する。
6. ダッシュボードの申告を確認して審査に提出する。

アカウント登録・審査提出・ストア公開は未実施です。
